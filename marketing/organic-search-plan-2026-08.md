# Searya organic search plan — August 2026

## What the current Search Console data says

The available Search Console sample is still too small to support statistically reliable query decisions. It is dominated by the branded query `searya`, with isolated unrelated impressions. The site should therefore avoid claiming keyword traction and build around specific task intent until non-brand query data accumulates.

## Measurement rule

Review the previous 28 days every week. Prioritize a query when it has at least 20 impressions, an average position between 6 and 30, and a page that matches its intent. Improve the existing page before creating another near-duplicate URL. Do not invent traffic, ranking or competition figures.

## Publishing rule

- Each tool page links to its industry versions, related guides and related tools.
- Each industry page contains a unique scenario, table, FAQ set, title, description, H1 and canonical URL.
- Each guide links to its working tool and related guides.
- Thin marketplace-era pages stay out of the production sitemap and return 410 in production.
